Browser-based learning tools for classmates. No account, installation, or coding needed.

One file. Open it anywhere.

  1. Choose a visualization and select Download HTML.
  2. Find the .html file in your Downloads folder.
  3. Double-click it to open in your browser. After downloading, it works offline.

You can also select Open to try a finished visualization online. A laptop is recommended for interactive diagrams.

Need help opening a file?

Keep the .html extension. If it opens in an editor, right-click the file and choose Open With, then your browser. If the download opens in a tab, use your browser’s Save page option. On a phone, use the online Open button; downloaded HTML handling varies by device.
